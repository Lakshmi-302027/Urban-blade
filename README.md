# 💈 Urban Blade — Luxury Men's Grooming Atelier (BTM Layout)

A high-conversion, modern single-file landing page template specifically engineered for upscale men’s salons, barbershops, and grooming lounges. Built with an editorial luxury light aesthetic (Warm Alabaster, Champagne Bronze, and Deep Charcoal) and integrated with a zero-backend WhatsApp direct-dispatch booking engine.

---

## 📸 Overview & Live Highlights

- **Visual Tone:** Editorial luxury, masculine, modern, warm light palette (No generic dark/cluttered barbershop look).
- **Target Audience:** Working professionals, tech leads, and modern gentlemen in Bengaluru (BTM Layout, Koramangala, HSR Layout, ORR).
- **Core Conversion Engine:** 1-Click interactive WhatsApp appointment dispatch (no database or paid booking software subscription required).
- **Mobile-First UX:** Sticky quick-action dock (`Book Chair` + `Direct Call`) for mobile visitors.

---

## ✨ Features

1. **⚡ Urgency & Trust Architecture**
   - Live availability ticker with limited-slot copy.
   - First-visit incentive callout (`FIRSTBLADE20` coupon trigger).
   - Social proof badges with verified Google rating counters.

2. **📋 Editorial Grooming Menu & Category Filter**
   - Live interactive JavaScript filtering (`All`, `Hair Craft`, `Beard & Shave`, `Scalp & Skin`).
   - Clear service durations (e.g., *35 mins*, *45 mins*) to help clients schedule around work meetings.
   - Dotted rate-card layout with instant `+ Select Service` quick-binding to the booking form.

3. **📦 Value-Stacked Packages (Bento Grid)**
   - Tiered packages (*Executive Express*, *The Bengaluru Club*, *The Royal Sovereign*).
   - Clear bulleted value comparisons and target use cases.

4. **💬 WhatsApp Booking Dispatcher**
   - Automatically compiles customer name, chosen service, preferred date, preferred time slot, and applied promo code into a pre-formatted WhatsApp text.
   - Sets dynamic minimum date constraint (`min=today`) via native JavaScript.

5. **📍 Local SEO & Trust Signals**
   - Embedded Google Map placeholder centered on BTM Layout 2nd Stage.
   - Local landmarks (Near Udupi Garden Signal, 7th Main Road).
